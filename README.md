# Rainmeter YouTube Music App Overlay

## System Requirements

> YouTube Music Download Link: https://github.com/pear-devs/pear-desktop/releases/download/v3.11.0/YouTube-Music-Web-Setup-3.11.0.exe
>
> Rainmeter: https://www.rainmeter.net/
>
> WebNowPlaying: https://github.com/keifufu/WebNowPlaying-Rainmeter/releases/download/2.0.7/WebNowPlayingRedux_2.0.7.rmskin

## Installation Guide

1. Install the provided YouTube Music application.
2. Install Rainmeter.
3. Open Rainmeter.
4. Download the `YTMusicPlayer.rmskin` file.
5. Download the `WebNowPlayingRedux.rmskin` file.
6. Double-click `WebNowPlayingRedux.rmskin`, change the installation type from **Skins** to **Plugins**, then click **Install**.
7. Double-click `YTMusicPlayer.rmskin` and click **Install**. After installing the skin, try using **Refresh All** in Rainmeter once again.
8. If the `YTMusicPlayer` skin appears, open the Rainmeter folder list, select `Player.ini`, and click **Load**.
